Architecture technique

Architecture MVC du système Power GPI.

Une organisation claire entre l’interface utilisateur, les contrôleurs Laravel, les modèles métiers et la base de données.

React + ViteLaravel APISanctumPostgreSQL / SQLite

Flux principal

Comment une demande traverse le système.

Exemple : un utilisateur consulte la liste des équipements ou déclare un incident.

01 Vue

Frontend React

Pages, formulaires, dashboard et composants dans frontend/src.

→
02 Route

API Laravel

La requête arrive dans backend/routes/api.php.

→
03 Contrôleur

Controller

Le contrôleur valide, orchestre et applique les droits d’accès.

→
04 Modèle

Model

Les modèles Eloquent lisent ou modifient les données métier.

→
05 Données

Database

Les informations sont persistées dans SQLite ou PostgreSQL.

Retour de la réponse

Database → Model → Controller → Resource JSON → Frontend React

Organisation réelle

Les dossiers MVC dans le projet.

MModel

Modèles métier

Représentent les données et leurs relations.

  • backend/app/Models/User.php
  • backend/app/Models/Equipement.php
  • backend/app/Models/Incident.php
  • backend/app/Models/Alerte.php
CController

Contrôleurs API

Reçoivent les requêtes, contrôlent les rôles et appellent le métier.

  • backend/app/Http/Controllers/AuthController.php
  • backend/app/Http/Controllers/EquipementController.php
  • backend/app/Http/Controllers/IncidentController.php
  • backend/app/Http/Controllers/AlerteController.php
VView

Interface et JSON

React affiche l’interface, tandis que les Resources Laravel formattent les données JSON.

  • frontend/src/features/
  • frontend/src/components/
  • backend/app/Http/Resources/
  • frontend/public/vitrine/

Exemple concret

Consultation des équipements.

1
React

La page Équipements appelle GET /api/equipements.

2
Route

backend/routes/api.php transmet la demande au contrôleur.

3
Controller

EquipementController applique les filtres, la pagination et les droits.

4
Model

Equipement interroge la table equipements.

5
Resource + View

EquipementResource renvoie le JSON que React affiche dans le tableau.
